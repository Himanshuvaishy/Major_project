# Wanderlust 🌍

A full-stack travel explorer application where users can discover, list, and review accommodations—deployed on Render!

🔗 **Live Demo:** https://major-project-8pbu.onrender.com

---

## ✨ Features

- **Browse Listings**  
  Explore destinations with images, descriptions, and interactive maps.

- **User Authentication**  
  Sign up/login with secure sessions. Authenticated routes for adding/editing content.

- **Host Controls**  
  Create, edit, or delete your own listings.

- **Review System**  
  Users can leave reviews and ratings on listings.

- **Image Uploads**  
  Upload multiple images per listing via Cloudinary.

- **Map Integration**  
  View listing locations on a Mapbox-powered map.

- **Responsive Design**  
  Works beautifully on all devices using responsive UI.

---

## 🛠️ Tech Stack

| Layer     | Technology                          |
|----------|-------------------------------------|
| Frontend | React, Tailwind CSS/DaisyUI         |
| Backend  | Node.js, Express.js                 |
| Database | MongoDB with Mongoose               |
| Auth     | JWT or Passport.js                  |
| Storage  | Cloudinary (images)                 |
| Maps     | Mapbox API                          |
| Deployment | Render (frontend and backend)     |
